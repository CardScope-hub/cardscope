CardScope — język polski i angielski (PL / EN)

CO ZMIENIA AKTUALIZACJA
Przełącznik PL / EN obok wyboru waluty. Wybór języka zostaje zapamiętany
w danej przeglądarce / aplikacji na tym urządzeniu. Zmiana nie przeładowuje strony.
Tłumaczenia obejmują interfejs, formularze i komunikaty aplikacji,
ekran konta oraz udostępniony binder.
Język interfejsu nie zmienia języka skanowanych kart, nazw kart,
własnych nazw binderów ani danych zapisanych w kolekcji.
Funkcja tłumaczenia treści kart na polski pozostaje osobną funkcją.

JAK WGRAĆ NA GITHUB
1. Jeśli masz niezapisane zmiany w kolekcji, zsynchronizuj konto.
2. Rozpakuj ten ZIP na komputerze.
3. Otwórz repozytorium cardscope-hub/cardscope na GitHub, gałąź main.
4. W głównym folderze (tam, gdzie app.html) kliknij Add file -> Upload files.
5. Przeciągnij WSZYSTKIE pliki z rozpakowanego ZIP-a, oprócz INSTRUKCJA.txt.
   Wgrywaj same pliki, nie folder, w którym je rozpakowano.
6. Zapisz zmianę przyciskiem Commit changes.
7. Poczekaj, aż GitHub Pages zakończy publikowanie. Otwórz cardscope.pl.
   Na komputerze odśwież stronę przez Ctrl + F5.
   Na telefonie zamknij i uruchom aplikację ponownie; jeśli pojawi się
   komunikat o aktualizacji, zastosuj ją.
8. W nagłówku, obok PLN / EUR / USD, wybierz EN. Wybierz PL, aby wrócić.

To mała paczka aktualizacyjna, a nie samodzielna kopia całej aplikacji.
Podmień pliki o tych samych nazwach i dodaj nowe i18n-en.js, i18n.js, i18n.css.
Pozostaw pozostałe pliki repozytorium, bazy kart i modele skanera.
Nie usuwaj ani nie zmieniaj CNAME, supabase-config.js czy ustawień domeny.
Nie trzeba nic konfigurować w Simply ani Supabase.
