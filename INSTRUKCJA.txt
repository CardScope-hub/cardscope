CARDSCOPE — OSTATNIO DODANE W KOLEKCJI ZNAJOMEGO

To mała aktualizacja istniejącej aplikacji. Paczka nie zawiera baz kart
ani poprzednich dodatków i nie zastępuje całego projektu.

1. SUPABASE — WYKONAJ RAZ
Otwórz projekt Supabase, następnie SQL Editor > New query.
Skopiuj całą zawartość pliku 08-ZNAJOMI-OSTATNIO-DODANE.sql,
wklej ją do edytora i kliknij Run.
Skrypt wymaga działającego wcześniej podglądu kolekcji znajomych.
Nie kasuje kart, binderów, kont ani dotychczasowych funkcji.

2. GITHUB — PODMIEŃ CZTERY PLIKI
W repozytorium strony, w tym samym folderze co obecny app.html,
wgraj i zastąp:
  app.html
  sw.js
  friend-view.js
  social-client.js
Nie wgrywaj całego folderu output ani ZIP-a. Nie usuwaj innych plików.
Plik SQL uruchamiasz w Supabase; samo wgranie go do GitHub nie wystarczy.

3. ODCZEKAJ NA PUBLIKACJĘ GITHUB PAGES
Po zakończeniu publikacji odśwież stronę. W aplikacji na telefonie
zamknij ją i uruchom ponownie. Jeżeli nadal widzisz starą wersję,
otwórz stronę w przeglądarce, odśwież i uruchom aplikację ponownie.
Nie trzeba usuwać aplikacji ani czyścić danych kolekcji.

4. UŻYWANIE
Znajomi > profil znajomego > Karty > Sortuj karty > Ostatnio dodane.
Najnowsze karty pojawiają się na początku. Sortowanie obejmuje całą
widoczną kolekcję, również kolejne strony i wyniki wyszukiwania.
Karty bez zapisanej daty dodania są na końcu. Aktualizacja ceny
ani synchronizacja nie zmieniają daty dodania karty.

Pozostają opcje sortowania po cenie. Ustawienia prywatności są
sprawdzane przez dotychczasowy mechanizm podglądu znajomych.

WERYFIKACJA
Sprawdzono składnię JavaScript oraz działanie interfejsu w Happy DOM.
W testowej bazie PostgreSQL (PGlite) sprawdzono sortowanie całej
kolekcji, paginację, wyszukiwanie, brakujące daty, niezmienność kolejności
po odświeżeniu ceny, brak ujawniania ukrytych danych i uprawnienia.
Testy korzystały z zastępczej implementacji dotychczasowej funkcji
podglądu. Nie uruchamiano migracji w Twoim Supabase ani testów
na rzeczywistym telefonie. Aktualizacja nie jest jeszcze opublikowana.
