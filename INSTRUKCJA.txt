CARDSCOPE — KOSTKA TYLKO NA EKRANIE GŁÓWNYM
Wersja: tabletop-home-1

Ikona otwierająca licznik jest widoczna wyłącznie w zakładce „Start”.
Po przejściu do kolekcji, binderów, tradingu, skanera i pozostałych widoków
znika; po powrocie na Start pojawia się ponownie.
Kostka otwierająca menu wewnątrz trwającej gry działa jak dotychczas.

To mała poprawka do ostatniej wersji z obróconymi punktami
i zaokrąglonymi polami (tabletop-4).

1. Rozpakuj ZIP.
2. W repozytorium GitHub podmień 3 pliki obok dotychczasowego app.html:
   app.html, tabletop.css, sw.js.
3. Zapisz commit i poczekaj na zakończenie publikacji GitHub Pages.
4. Otwórz stronę z internetem, zastosuj aktualizację, jeżeli się pojawi,
   i odśwież stronę. Aplikację z ekranu głównego zamknij i uruchom ponownie.

Nie twórz dodatkowego podfolderu ani nie usuwaj innych plików aplikacji.
INSTRUKCJA.txt i SUMY-SHA256.txt są pomocnicze; nie musisz ich wgrywać.

Sprawdzono widoczność kostki podczas przełączania widoków, jej powrót na
ekran główny oraz zachowanie kostki menu gry. Zaktualizowano wersję pamięci
podręcznej aplikacji, żeby poprawka mogła zostać pobrana na telefonie.
